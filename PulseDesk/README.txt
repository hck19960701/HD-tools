PulseDesk v2.7 — Freshdesk × Outlook Classic 首次回覆監控
=========================================================

【PulseDesk 做甚麼】
- 客戶寄信到 support@ / servicedesk@，郵件一到（Outlook 新郵件事件，即時偵測）就開始 15 分鐘倒數
- Freshdesk 建立工單後，自動按主旨及客戶電郵合併到同一張工單（計時仍由客戶寄信時間開始）
- 同事回覆客戶後倒數自動停止：Freshdesk 回覆（Re: Tkt#123456），或直接用 Outlook 回覆同一主旨
- 同一客戶以相同主旨再來信，不會重新計時；超過 5 分鐘仍未有 Freshdesk 工單會標示出來
- 10 分鐘轉黃、13 分鐘轉橙、15 分鐘轉紅，並以提示聲、桌面通知及 Windows 彈窗提醒
- 回覆後工單移到「待分派」；分派同事後用看板跟進（跟進中 / 等待客戶 / 已解決）
- 「Outlook 分類」頁：按你在 Outlook 設定的分類（Categories）列出郵件，顯示等了多少日、
  旗標期限及 Tkt 號碼，點擊即在 Outlook 打開
- 統計頁：每日達標率、回覆時間分佈、每小時工單量、同事工作量
- 只讀取郵件，不會刪除、移動、修改或自動寄出郵件。資料只保存在你的電腦。

【第一次使用】
1. 安裝 Python 3：https://www.python.org/downloads/windows/
   安裝畫面「一定要」勾選 "Add python.exe to PATH"。
2. 雙擊 build_exe.bat，等候 1 至 2 分鐘，會產生 PulseDesk.exe。
3. 打開 Outlook Classic，然後雙擊 PulseDesk.exe。
   PulseDesk 會以獨立視窗（Microsoft Edge 應用程式模式）打開。
4. 到「設定」加入同事名單（名稱及電郵），按「儲存設定」。
5. 在看板上按「啟用通知」及「啟用提示聲」。

由舊版升級：解壓新版本到原本的資料夾（覆蓋舊檔案），再雙擊 build_exe.bat。
build_exe.bat 會自動關閉正在運行的舊版本（包括背景中的）、更新 PulseDesk.exe、
更新桌面上的 PulseDesk，然後打開新版本。舊資料及設定會保留。
左下角顯示版本號碼（例如 v2.7），可用來確認已經更新。
v2.6 起，打開新版本時如果發現舊版本仍在運行，會自動關閉舊版本。

想先預覽界面：雙擊 demo.bat（使用虛擬資料，需要已安裝 Python）。
想開機自動啟動：建立 EXE 後雙擊 add_to_startup.bat。

【日常使用】
- 關閉 PulseDesk 視窗後，程式仍會在背景監控，並用 Windows 彈出視窗提醒。
  再次雙擊 PulseDesk.exe 就會重新打開視窗。
- 要完全停止，按左下角「結束程式」。
- 不需要回覆的寄件人（例如供應商、系統通知）：在工單詳情按「以後忽略此寄件人」，
  或在「設定 → 忽略寄件人 / 忽略主旨」加入。
- 預設只掃描你自己信箱的收件匣及寄件備份。要監控共用信箱或其他資料夾，
  到「設定 → 掃描的資料夾 → 選擇資料夾…」勾選後儲存。
- 「立即同步」只讀取上次掃描之後的新郵件（通常 1 秒內完成），完成後會顯示找到多少封新郵件。
  只有「系統狀態 → 完整重新掃描」才會重新讀取全部，平時不需要使用。
- 新郵件由 Outlook 即時通知 PulseDesk；每 60 秒另有後備檢查，每 120 分鐘完整覆查一次。
  掃描使用 Outlook 的清單功能，只讀取新郵件，已處理的郵件不會再打開，不會令 Outlook 變慢。
  「系統狀態 → 完整重新掃描」會清除掃描紀錄重新讀取（工單、分派及備註不會刪除）。
- 「Outlook 分類」預設讀取收件匣及其子資料夾，但不包括超過 5,000 封的大資料夾；
  你在 Outlook 改分類時會即時更新。可在「設定 → 讀取分類的資料夾」修改。
- 已在 Freshdesk 分派、不需要在 PulseDesk 分派的工單：按「待分派」欄的「全部已處理」。
  回覆後超過 24 小時仍未分派的工單會自動移出「待分派」（可在設定修改）。
- 事後補記的「已回覆」（例如「需人手確認」）不知道真正回覆時間，不計入達標率及平均回覆時間。
- 某個資料夾暫時讀取失敗（例如共用信箱網絡問題）時，其他資料夾照常監控，失敗的會自動重試；
  暫時讀取失敗的郵件會在下次掃描再讀取，不會漏掉。
- 如果 PulseDesk 顯示「Outlook 沒有回應」，請切換到 Outlook，看看有沒有對話框
  （例如「有程式嘗試存取電子郵件」）等待你回應。

【誰回覆了客戶】
- 用 support@ / servicedesk@ 回覆（包括 Freshdesk 回覆）：按簽名辨認同事。
  只看郵件的新回覆部分，下面引用的舊郵件（From: / On ... wrote: 之後）不會計算。
  簽名要獨立成行並完全相同（大小楷、逗號、and / & 不影響），多行簽名優先。
- 用自己的信箱回覆：按寄件人電郵或名稱辨認，不看簽名（因為簽名可能與其他同事相同）。
- 在「設定 → 同事名單及簽名」修改；兩位同事簽名相同會顯示提示；可以貼上郵件內容測試。
- 工單卡片、工單詳情、全部工單、統計頁（誰首次回覆了客戶）都會顯示回覆的同事；
  辨認錯誤可在工單詳情「回覆同事 → 修正」。

【判斷錯誤時】
- 工單詳情 →「修正判斷」：
  · 不是客戶請求：可選只忽略這一張，或以後忽略此寄件人 / 整個網域 / 相同主旨
  · 合併到另一張工單：同一件事被當成兩張工單時使用
  · 連結 Freshdesk 工單號碼：Freshdesk 已建立工單但未能自動配對時使用
  · 這不是回覆：偵測到的「回覆」其實不是回覆客戶，工單會重新計時
- 倒數卡片上的「✕ 不是請求」可以快速處理供應商、系統通知等郵件。
- 所有修正會記錄在「系統狀態 → 修正紀錄」。

【匯出診斷資料】
- 「系統狀態 → 匯出診斷資料」會匯出每封已讀取郵件的判斷類型、原因及處理結果（CSV）。
- 可選擇遮蓋客戶電郵、名稱及主旨；不包含郵件內文（只包括辨認到的簽名行）。
- 在「判斷正確？」一欄填 Y / N，錯誤的在「正確應該是」寫下應有判斷，再把檔案發給開發者分析。

【注意】
- Outlook 如彈出「有程式嘗試存取電子郵件」，請選擇允許。
- 部分防毒軟件可能誤報自行建立的 EXE，屬常見情況，可加入信任清單。
- 資料及設定位置：%APPDATA%\PulseDesk
  （pulsedesk.db 工單資料、config.json 設定、pulsedesk.log 記錄）
